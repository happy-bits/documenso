Ask clarifying questions about the current task, one at a time, until the user says stop.

Prefer questions that surface hidden assumptions, edge cases, or ambiguous requirements over shallow or generic ones. If you run out of meaningful questions, say so rather than inventing filler ones. Ask each question using the AskUserQuestion tool.

Don't change any code.
